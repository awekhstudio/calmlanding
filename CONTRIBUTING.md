# Contributing

Thank you for improving CalmLanding.

- Report bugs with clear reproduction steps, browser details, and viewport size.
- Keep pull requests small, focused, and aligned with the calm visual direction.
- Discuss new dependencies before proposing them. The default expectation is dependency-free code.
- Test at 360, 390, 768, 1024, 1280, and 1440 px.
- Check keyboard navigation, visible focus, FAQ behavior, the mobile menu, and reduced motion.
- Validate semantic HTML and update documentation when behavior changes.

Helpful commit examples:

- `fix: correct mobile navigation spacing`
- `docs: clarify preview replacement`
- `feat: improve active navigation state`
